2nd Place · 1st Codeit PowerBoost Demo Day

Momentum

A goal-management app that helps people stop setting unrealistic goals by breaking them into small, trackable “moments”.

Role
Front-end Developer
Period
Apr 2024 – Feb 2025
Tech
React, TypeScript, OpenAI API

Overview

Big goals often fail because they are set too ambitiously and never broken down. Momentum lets users split annual goals into weekly and daily moments, check progress as a checklist, and share achievements with friends through a feed.

What I did

  • Implemented the initial overall styling and the “Moment Creation” page UI in React.
  • Handled data processing and connected automation features through API integration.
  • Integrated a GPT-based recommendation API that suggests detailed goals, or “moments”, from what the user types in.

Result

  • Won 2nd place at the 1st Codeit PowerBoost Demo Day.
