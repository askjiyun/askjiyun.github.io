Deep Learning Project · Review Analysis

Camchelin

A deep learning system that analyzes restaurant reviews and turns them into clear, category-level summaries.

Role
Deep Learning Member
Period
Sep 2024 – Feb 2025
Tech
pko-T5, OpenAI GPT fine-tuning, Python

Overview

Using platform and user review data, Camchelin identifies positive and negative feedback about a restaurant and extracts the keywords behind it.

What I did

  • Fine-tuned Hugging Face's pko-t5-base model to extract keywords from review text and classify them as positive or negative.
  • Grouped keywords into five categories (taste, service, atmosphere, sanitation, cost-effectiveness).
  • Generated a representative sentence for each category with a fine-tuned GPT model.
  • Owned model training, performance evaluation, and results analysis throughout the project.
