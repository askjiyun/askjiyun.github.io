Deep Learning Project · Review Analysis

Camchelin

An AI-powered restaurant review platform that brings both positive and negative feedback to light, helping users discover the strengths and weaknesses of restaurants beyond ratings alone.

Role
AI Developer
Period
Sep 2024 – Feb 2025
Tech
Python, Hugging Face Transformers, pko-T5, OpenAI GPT Fine-tuning, FastAPI, Docker

Overview

Restaurant review platforms often make it difficult to identify negative feedback hidden behind high ratings and overwhelmingly positive reviews. Users must read through numerous reviews to understand a restaurant's actual strengths and weaknesses.

Camchelin is an AI-powered restaurant review platform designed to address this problem. It extracts positive and negative keywords from customer reviews and generates representative summaries across five categories: taste, service, cleanliness, atmosphere, and value for money.

By presenting both positive and negative feedback, the platform helps users make more informed and balanced dining decisions.

AI System Pipeline

Developed a two-stage NLP pipeline to analyze restaurant reviews collected from Naver Place, Kakao Map, and user submissions.

Key Contributions

  • Review Data Collection & Preparation: Collected and organized restaurant reviews from Naver Place and Kakao Map. Used the OpenAI API to generate labeled training data containing review keywords and their corresponding positive or negative sentiment labels.
  • NLP-Based Review Analysis Pipeline:Contributed to developing a two-stage NLP pipeline combining a fine-tuned pko-T5 model for keyword extraction and sentiment labeling with a fine-tuned GPT model for category classification and representative sentence generation.
  • GPT Fine-tuning & Model Evaluation: Prepared training and validation datasets in JSONL format and fine-tuned GPT-4o-mini to classify review keywords into five categories and generate natural Korean summaries. Evaluated model outputs using category accuracy, ROUGE, BLEU, and BERTScore.
  • Model Evaluation & Performance: Evaluated the fine-tuned GPT model on 29 validation samples, measuring 99.3% category coverage, a BERTScore F1 of 0.77, a METEOR score of 0.18, and an average response time of 6.8 seconds.
  • FastAPI-Based Model Serving:Developed REST API endpoints for both NLP models, enabling review text and extracted keywords to be processed and returned as structured JSON responses for integration with the web service.
  • Docker Containerization & Deployment: Configured Docker environments for both model APIs, including dependencies and server execution settings. Containerized and deployed the APIs to make the NLP pipeline accessible to the application.

Outcome & Learnings

Developed and integrated a two-stage NLP pipeline that transforms unstructured restaurant reviews into sentiment-labeled keywords and category-specific summaries, enabling users to explore restaurant strengths and weaknesses through the Camchelin web platform.

Through this project, I gained hands-on experience across the AI development lifecycle, from data preparation and model fine-tuning to evaluation, API development, and Docker-based deployment.

The experience highlighted the importance of building reliable connections between individual AI models and delivering their outputs in a format that can be used effectively within a real application.
