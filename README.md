# askjiyun.github.io

Personal website of Jiyoon Oh — https://askjiyun.github.io/

Plain static HTML/CSS, no build step. Edit `index.html` or the pages in `projects/` and push; GitHub Pages serves the files as they are.

- `index.html` — home page
- `projects/*.html` — project detail pages
- `assets/style.css` — all styles
- `assets/img/` — images, `assets/Jiyoon_Oh_CV.pdf` — CV
