제1회 코드잇 파워부스트 데모데이 2위

Momentum

비현실적인 목표 설정을 막기 위해, 큰 목표를 작게 쪼갠 ‘모먼트’로 관리하도록 돕는 목표 관리 앱입니다.

Role
프론트엔드 개발
Period
2024.04 – 2025.02
Tech
React, TypeScript, OpenAI API

Overview

큰 목표는 너무 거창하게 세우고 잘게 나누지 않아 실패하는 경우가 많습니다. Momentum은 연간 목표를 주간·일간 모먼트로 나누고, 체크리스트로 진행 상황을 확인하며, 피드를 통해 친구들과 성취를 공유할 수 있게 합니다.

What I did

  • React로 초기 전체 스타일링과 ‘모먼트 생성’ 페이지 UI 구현
  • API 연동을 통한 데이터 처리 및 자동화 기능 연결
  • 사용자가 입력한 내용을 바탕으로 세부 목표(모먼트)를 추천하는 GPT 기반 추천 API 연동

Result

  • 제1회 코드잇 파워부스트 데모데이 2위 수상
